# SCHOOLONE — PROMPT MAÎTRE POUR CLAUDE CODE

Construis une super-application mobile appelée SCHOOLONE.

Slogan :
« Tout pour l’enfant, en un seul endroit. »

OBJECTIF
Créer une plateforme complète dédiée aux enfants, parents, élèves, enseignants, écoles et vendeurs. Ce n’est PAS une simple boutique de fournitures.

FONCTIONNALITÉS PRINCIPALES
- Profils parents et plusieurs enfants
- Scolarité complète
- Écoles, classes et enseignants
- Emploi du temps
- Devoirs et évaluations
- Notes et bulletins
- Assistant IA éducatif
- Quiz et révisions
- Fournitures scolaires
- Listes de fournitures par école/classe
- Scanner IA d’une liste de fournitures
- Fonction « Préparer ma rentrée »
- Livres
- Uniformes et vêtements scolaires
- Marketplace multi-vendeurs
- Panier, commandes et paiements
- Livraison et suivi
- Cantine
- Transport scolaire
- Activités extrascolaires
- Documents scolaires
- Notifications
- Tableau de bord école
- Tableau de bord enseignant
- Tableau de bord vendeur
- Tableau de bord administrateur
- Internationalisation France/Afrique/international

STACK PAR DÉFAUT
Si aucune stack n’existe déjà :
- React Native
- Expo
- TypeScript strict
- Expo Router
- Supabase/PostgreSQL
- Supabase Auth
- Supabase Storage
- Zustand ou solution équivalente
- React Hook Form
- Zod

IMPORTANT
Commence par inspecter entièrement le projet existant. Ne supprime pas arbitrairement le travail existant. Adapte-toi à l’architecture existante si elle est cohérente.

CACHE
Créer un système de cache intelligent.

Services :
- cacheService
- startupService
- sessionService
- offlineService

Données pouvant être mises en cache :
- profil
- enfants
- école
- classe
- emploi du temps
- devoirs récents
- notifications
- catégories
- produits récemment consultés
- panier
- préférences

Stratégie :
CACHE-FIRST lorsque possible :
Cache → afficher rapidement → actualisation serveur en arrière-plan → mise à jour du cache → interface actualisée.

Ne jamais stocker de secrets ou tokens sensibles dans un cache non sécurisé. Utiliser un stockage sécurisé pour les informations d’authentification.

ÉTATS :
INITIALIZING
LOADING
READY
REFRESHING
OFFLINE
ERROR

Créer des Skeleton Loaders pour éviter les écrans blancs.

MODE HORS LIGNE
Si Internet est indisponible :
- afficher les données déjà disponibles en cache
- afficher « Vous êtes actuellement hors connexion »
- indiquer 🟠 Hors connexion
- au retour du réseau : 🟢 Connexion rétablie
- synchroniser automatiquement les données

ERREUR DE DÉMARRAGE
Ne jamais afficher un écran blanc.
Afficher :
« Impossible de charger votre espace. »
Bouton [Réessayer]
Et, si possible, [Continuer hors connexion].
